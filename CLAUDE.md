# Autonomous Project Instructions

When I give you a development or validation task:

1. Continue working until every requested item is completed.
2. Do not stop after only inspecting or planning.
3. Inspect the existing code before making changes.
4. Make the smallest safe changes necessary.
5. Run the relevant lint, tests, build and runtime validation.
6. Resolve confirmed errors and repeat validation.
7. Do not commit, push, change Git remotes, reset Git history or discard existing work.
8. Do not expose credentials, tokens or environment-variable values.
9. Do not replace live API data with hardcoded or mock data unless explicitly requested.
10. Preserve unrelated existing changes.
11. Ask a question only when essential information is genuinely unavailable.
12. When the task is complete, respond with:
